## Overview

Decision Systems Toolkit provides a practical set of browser-based analytics tools for making data-informed decisions. It combines statistical techniques frequently needed for product experiments, comparison tests, and measurement preparation, with no separate runtime or external library setup.

The lightweight interface is intended for both individuals and teams that want fast, accessible results. Common workflows include planning the required sample size, comparing means or proportions, and examining confidence intervals.

---

## Included Tools

- Operates fully in a web browser
- A/B testing calculator for experiment evaluation
- Welch t-test for mean comparisons
- z-test for proportion comparisons
- Sample size calculations for test planning
- Statistical power analysis for experiment preparation
- Newcombe confidence intervals for comparing proportions
- Offline-capable operation without external libraries

## Using the Toolkit

Load the project in a browser, then select the statistical analysis that matches your task.

A typical session looks like this:

1. Provide the observed measurements or experiment results.
2. Select a method, including an A/B test, Welch t-test, or z-test.
3. Examine the resulting confidence intervals, sample size projections, or power calculations.
4. Change the inputs and calculate again whenever you want to test another scenario.

Common applications include:

- Evaluating two product variants through an A/B test
- Planning how many observations an experiment will require
- Reviewing statistical power before data collection begins
- Quantifying uncertainty with confidence intervals
